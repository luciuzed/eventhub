# EVENTHUB

## Alur Kerja Web 

1. **Browser (Client Request):** Pengguna memasukkan URL situs atau mengklik tombol pada halaman. Browser kemudian mengirimkan HTTP Request melalui jaringan internet menuju server tempat website di-hosting.
2. **Web Server:** Server menerima permintaan tersebut, memproses rute atau file yang diminta, dan menyiapkan data yang diperlukan.
3. **Response:** Web Server mengirimkan kembali HTTP Response ke browser berupa file-file resource. Browser kemudian membaca, merender, dan menampilkan halaman web secara visual kepada pengguna.
